# Amp for Windows

A music and video player for Windows 10 and 11 (64-bit).

## Download

**[Download the latest version](https://github.com/tapuroy2002/Amp-releases/releases/latest)** · or visit **[tapuroy2002.github.io/getamp](https://tapuroy2002.github.io/getamp/)**

On the release page, under **Assets**:

| File | What it is |
|---|---|
| `Amp-Windows-Setup-v….exe` | Installer. **Pick this one.** Amp updates itself when a new version comes out. |
| `Amp-Windows-Portable-v….zip` | No install: unzip anywhere and run `Amp.exe`. Updates are downloaded by hand. |

## Installing

1. Run `Amp-Windows-Setup-v….exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. (The installer isn't code-signed yet.)
3. Follow the steps. Amp opens when it's done.

## Updates

When a new version is out, Amp shows **Update available** a few seconds after it starts. Click **Update now**: it downloads, installs and opens again by itself. Your songs, playlists and settings stay.
